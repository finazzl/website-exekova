How each page is scored

SEO, GEO and AEO (10 = no failing checks):

  • title length: Title between 30 and 65 characters so it shows in full in results
  • meta description: Description between 90 and 165 characters
  • single h1: Exactly one h1
  • canonical: A canonical URL
  • indexable: Not marked noindex
  • social tags: og:title, og:image and twitter:card present
  • WebPage schema: JSON-LD WebPage block
  • entity clarity (GEO): A definition sentence ("exekova is an autonomous work execution platform") or the category in the title, description or h1, so answer engines can attribute the page
  • answer content (AEO): Question-and-answer content on the page with FAQPage schema
  • depth: At least 250 words in main
  • image alt: Every image has alt text
  • dashes in copy: No em or en dashes in rendered copy
  • structure: At least two h2 headings

Sections: Each section needs a heading (or an accessible name), the heading needs an id so it can be linked, and the section needs at least 20 words.

Mobile-first responsiveness (10 = no failing checks, each checked at seven widths from 360px to 1440px):

  • no horizontal scroll: The page is never wider than the viewport at 360, 390, 430, 768, 1024, 1280 and 1440px
  • content inside the viewport: No visible element extends past the viewport edge
  • tap targets 24px+: Every link, button and control is at least 24x24 (inline links in running text and the skip link are exempt, as in WCAG 2.5.8)
  • text 11px+: No visible text below 11px
  • images sized: Images carry width and height so layout does not shift
  • no fixed widths: No element has a min-width wider than the viewport
  • navigation adapts: The drawer toggle is used up to 1100px and the desktop menus above it
  • viewport meta: width=device-width viewport meta present
  • inputs 16px+ on phones: Form fields are 16px or larger on phones so iOS does not zoom
  • 16px side gutter: Content keeps at least a 16px side gutter at every width
